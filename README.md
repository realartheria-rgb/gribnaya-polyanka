# Грибная Полянка — Учим Грибы

Интерактивное развивающее приложение для детей 4–5 лет по изучению съедобных и несъедобных грибов с озвучкой и играми.

## Запуск

Откройте `index.html` в браузере — приложение полностью автономно (JS, CSS и изображения встроены в один файл).

## Возможности

- **Лесная полянка** — интерактивная прогулка по лесу: поиск грибов в траве
- **Викторина** — «Съедобный или нет?» на скорость
- **Загадки** — угадывание гриба по силуэту
- **Энциклопедия** — карточки грибов с описаниями
- **Альбом наклеек** — коллекция за найденные грибы
- **Лесной календарь подарков** — ежедневные награды
- **Голосовая озвучка** и звуки леса
- Сохранение прогресса в localStorage

## Технологии

React 19 + Vite + TypeScript + Tailwind CSS 4. Собрано в один самодостаточный HTML-файл.

## Сборка из исходников

```bash
npm install
npm run build
```

Исходники — в папке `src/`.
